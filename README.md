# Mini Budsjettoversikt

Budsjettapplikasjon

## Om prosjektet

Mini Budsjettoversikt lar brukeren registrere inntekter og utgifter og få en enkel oversikt over økonomien.

Prosjektet er laget for å øve på frontend-utvikling, JavaScript, DOM-manipulering og Git/GitHub.

## Funksjoner

* Legge til inntekter og utgifter
* Velge kategori for hver transaksjon
* Automatisk beregning av inntekter, utgifter og saldo
* Enkel graf som sammenligner inntekter og utgifter
* Vise registrerte transaksjoner
* Slette transaksjoner
* Automatisk oppdatering av innholdet på siden
* Responsivt design for PC og mobil

## Teknologier

* HTML
* CSS
* JavaScript
* Git
* GitHub
